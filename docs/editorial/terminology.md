# Working Terminology

Status: controlled vocabulary; update during each chapter’s consistency pass

## Core distinctions

| Term | Canonical use | Avoid |
|---|---|---|
| output | An artifact or action produced | Treating output count as value |
| throughput | Accepted work crossing the complete operating path | Using as a synonym for activity |
| outcome | A changed customer, operational, or strategic condition | Calling shipment an outcome without an observed change |
| value | Outcome benefit net of cost, risk, maintenance, and alternatives | Equating value with model price or self-reported time saved |
| constraint | The capacity currently limiting the end-to-end system | Assuming the constraint is permanently human or technical |
| queue | Work waiting because a downstream capacity or decision is unavailable | Using “bottleneck” for every inconvenience |
| agent | A model-centred software system that can choose and use tools toward a goal within a bounded environment | Calling every chatbot, automation, or fixed workflow an agent |
| operating model | The system by which intent, authority, work, evidence, and learning are connected | Using it as a synonym for org chart or software stack |
| accountability | Answerability for an outcome and its consequences | Assigning moral or institutional accountability to software |
| Hidden Operational Debt | Accumulated operating liabilities that impose recurring delay, rework, coordination cost, or risk | Generic technical debt or any inefficient process |
| ATOM | Adaptive Transformation Operating Model; a governed learning loop defined in Chapter 4 | A platform, product, maturity badge, or acronym used before definition |

## Style controls

- Use “AI-native” only when a system was designed around model or agent capabilities, not as a decorative synonym for modern.
- Use “real-time” only when latency is specified and material.
- Distinguish assisted work, delegated execution, and autonomous action.
- Distinguish **REAL CASE**, **AUTHOR EXPERIENCE**, **ILLUSTRATIVE EXAMPLE**, and **HYPOTHETICAL FUTURE SCENARIO**.
- Do not call model output a decision unless authority to decide has actually been delegated.
