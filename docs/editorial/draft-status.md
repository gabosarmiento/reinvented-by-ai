## Private reading preview

The draft PR runs a Quarto HTML render and uploads the result as a GitHub Actions artifact. People with read access to this private repository can download the artifact, unzip it, and open `index.html` to read the book. The artifact expires after 14 days and is rebuilt by a later PR or draft-branch update. GitHub Pages is not enabled because Pages from this personal private repository would publish the manuscript publicly.
