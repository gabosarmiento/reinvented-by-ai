# Chapter 12 argument map

## Proposition

Build a controlled operating path around a decision before expanding authority: baseline, define context and rights, test safely, compare in shadow, release narrowly, and decide the next scope.

## Support

1. Real cases reveal missing context and hidden operator work.
2. Gates align authority with evidence, control, and recovery capability.
3. Shadow mode tests recommendation/context behavior but not live controls or economics.
4. Narrow release includes human load and downstream queue costs.
5. Named owners and retirement paths make transfer possible.

## Boundary

The 30-day order is a proposed template, not a universal timeline. A successful checklist does not certify security, safety, or legal compliance.
