# Chapter 7 argument map

## Proposition

Assign each step to a suitable executor, specify handoffs and authority, and preserve accountability for the complete outcome.

## Support

1. Workflow and agent architectures trade predictability against flexibility, latency, and cost.
2. Local automation can fragment the customer outcome unless one owner maintains end-to-end evidence.
3. Handoff contracts specify trigger, receiver, state, evidence, waiting state, and return route.
4. Multi-agent systems can help on separable work but introduce coordination, reliability, and token costs.
5. Graduated authority should follow observed performance on the selected task and boundary cases.

## Objection and response

**Objection:** The Synthesizer creates another senior bottleneck.

**Response:** The role's obligation is to improve interfaces and decision rights so fewer cases depend on personal synthesis; if its queue grows, the design has failed.

## Boundary

The ladder, handoff contract, and Synthesizer are proposed methods, not validated general frameworks. Vendor studies are narrow and company-reported.
